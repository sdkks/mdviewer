# Getting Started with MDViewer

## Installation

1. Download `MDViewer.app`
2. Drag to **Applications**
3. Double-click any `.md` file

## First Steps

### Open a File

- Double-click a `.md` file in Finder
- Or use `Cmd+O` from within MDViewer

### Navigate Between Files

- **Sidebar**: `Cmd+Shift+S` or `Cmd+B` to toggle the file tree
- **Fuzzy Picker**: `Cmd+K` then type to fuzzy-match file names
- **Links**: `Cmd+Click` any `.md` link to open it

### Export a Diagram

1. Open a file containing Mermaid diagrams
2. Go to **File → Export Mermaid Diagram**
3. Choose **SVG** (lossless) or **PNG** (raster)
4. Each diagram gets its own save panel

### Customize Appearance

Open **Preferences** (`Cmd+,`) to switch between 7 themes. The sidebar and code highlighting adapt automatically.

## Tips

- Hover over an internal `.md` link to see "Open in MDViewer" tooltip
- Focus a diagram with `Tab`, then use `+`/`-` to zoom
- Mermaid syntax errors show a themed error box instead of blank space
